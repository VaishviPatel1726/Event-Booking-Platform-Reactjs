# 🎟️ Event Booking Platform

## 📌 About The Project

The **Event Booking Platform** is a web application developed using React JS that allows users to discover events, explore event details, and book tickets online.

The main goal of this project is to make event discovery and ticket booking simple and user-friendly. The platform also provides organizer features to create, update, delete, and manage events.

This project is inspired by the event discovery and booking experience of BookMyShow.

## ✨ Features

### 👤 Customer Features
- User Registration and Login
- Browse All Events
- Search Events
- Filter Events by Category
- View Event Details
- Book Event Tickets
- View Booking History
- Cancel Bookings
- Logout

### 🛠️ Organizer Features
- Create New Events
- Edit Existing Events
- Delete Events
- View Event Bookings
- Manage Available Seats

## 🧑‍💻 Technologies Used

- **Frontend:** React JS
- **Routing:** React Router DOM
- **State Management:** Redux Toolkit
- **API Requests:** Axios
- **Backend / Data Storage:** JSON Server
- **UI Framework:** Bootstrap
- **UI Components:** React Bootstrap
- **React Features:** Hooks, Components, Props and State
- **Development Tool:** Vite

## 📂 Project Modules

### 1. User Authentication
Allows customers to register, log in, and access the platform.

### 2. Event Management
Allows organizers to create, update, delete, and manage event information.

### 3. Event Discovery
Users can browse, search, filter, and view details of available events.

### 4. Ticket Booking
Users can select the number of tickets and book events according to seat availability.

### 5. Booking History
Users can view their previous bookings and cancel eligible bookings.

## 🗃️ Data Structure

The application uses the following collections in `db.json`:

- **users** — stores user information.
- **events** — stores event details and seat availability.
- **bookings** — stores ticket booking information.

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project Folder

```bash
cd event-booking-platform
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start JSON Server

```bash
npm run server
```

The JSON Server runs on port `5000`, if configured in the project.

### Step 5: Start the React Application

Open another terminal and run:

```bash
npm run dev
```

Open the local URL displayed in the terminal to view the application.
